# Lecture AI

Turn lecture audio into:
- Clean transcript
- Structured notes
- Exam summary
- MCQs
- Flashcards
- AI Q&A chatbot

## Setup

1. Install Python 3.10+
2. Install dependencies:
pip install -r requirements.txt

3. Install Ollama:
https://ollama.com

4. Pull model:
ollama pull llama3.2

5. Start Ollama:
ollama serve

6. Run app:
streamlit run app.py

Open http://localhost:8501 in your browser.
